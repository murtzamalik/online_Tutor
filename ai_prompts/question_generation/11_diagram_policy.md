# Diagram & graph policy (D-27)

1. **No AI-generated images**, ever, for questions or mark schemes.
2. **Apparatus library** — a fixed set of vector diagrams (SVG), drawn once by a designer and approved
   by the content team, each with an id, board applicability and label slots.
   Pilot set (Chemistry): gas syringe, upside-down measuring cylinder over water, conical flask on
   balance with cotton wool, burette + conical flask titration, electrolysis cell (inert electrodes),
   Bunsen + evaporating basin, filtration funnel, simple distillation, fractional distillation column,
   chromatography paper in beaker, thermometer in polystyrene cup (calorimetry), test-tube with delivery
   tube into limewater, flame test wire, water bath.
   The generator may only reference these ids; labels are text slots filled by code.
3. **Charts are drawn by code** from data: `LINE`, `SCATTER`, `BAR` or `TABLE`.
   - Calculation templates: data comes from the template's variables and computed steps
     (`data_source = "template_variables"`), so the graph always matches the numbers.
   - Other items: `inline_data` from the model is allowed only for qualitative trends; code checks
     the data against any values stated in the question and mark scheme.
4. Structural formulae / displayed formulae / dot-and-cross diagrams: rendered by code from a
   chemical notation (SMILES for organic displayed formulae; a simple shell/electron JSON for
   dot-and-cross). The generator describes the species; code draws it. (Phase: pilot, organic chemistry
   and bonding topics.)
5. Every diagram has alt text generated by code from its id/labels/data (accessibility, WCAG 2.2 AA).
6. Photos of real apparatus or people: not used.
